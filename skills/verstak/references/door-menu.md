# Empty invocation: readiness first, then the question

The user typed `/verstak` alone. **Check whether the work can happen before asking what they want** — otherwise they explain a task to a setup that can't carry it out. **Start nothing yourself**, even when the repair is obvious: each rung ends in an offer the user confirms. Never answer with a list of method names.

## The readiness ladder

Top down. A rung passes → say nothing. A rung fails → name it and stop there; no list of failures.

**1 · Transport.** Do the `verstak_*` tools answer (the first graph read shows it)? No → `methods/establish-mcp.md`, and stop. They answer but there's no project graph → offer the door's Survey row "no project graph".

**2 · Repository.** `AGENTS.md` missing, or its stamp below the contract (a date or no stamp counts as below) → `methods/align.md`.

**3 · Channel.** Two different things:
- **the role's seat** — exists, and held? (`verstak_channel(action="list")`, or the `CHANNEL` line on the role);
- **this session's signature** — named? A miss shows as an authorless or refused write, not a missing board row.

Either missing and the work will write → offer the seat: one `verstak_stand` (the door's `Start`); without the bridge, `methods/establish-mcp.md`.

**4 · Watch.** The repo names an agent role and the user is leaving or asked you to work alone → offer `methods/autonomous.md`. The watch doesn't work the queue by itself: name what's calling; the user's word becomes the signal. Offered, never required.

## Then — orientation

At most two reads: `verstak_orient(realm=<graph>, focus=<focus holon>)` and, if named, the role. Free: `git status --short`, the branch.

| What you see | What it tells you |
|---|---|
| **risks calling** in the role's queue | the one class that won't remind you of itself |
| a dirty tree or unmerged branch | the round didn't end in a commit |
| tensions are mostly "close the structure" | structure without sense on its links |
| tensions are mostly "answer or end a question" | questions piling up |
| many free questions, a wall of top-level actions | an unassembled field, not busyness |
| live transformations long unmoved | a stalled direction looks like a moving one |
| recent changes by another session | someone is near; prevent the collision |

## Only now — the question

Ask **from what you saw**: "I see this — where are we going?", not "how can I help?". Up to fifteen lines:

1. **Status** — graph, holon, what's moving; no method words.
2. **Readiness** — only a failed rung and its repair, one line.
3. **Two or three pointers** — what you see (a number or name) → what it means → a phrase they can type, in their words, in the invocation form they used.
4. **One question** — where are we going. Nothing urgent → say so.

Numbers beat adjectives: "58 calling, three of them risks". A pointer without a number or name, or without grounds, is noise — don't offer it.
