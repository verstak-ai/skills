# given_as — the decision tree, the nests, and the arrow matrix

Read by the `writing` method (`methods/writing.md`, Decision 2) when a phenomenon's `given_as` is unclear, or an arrow on a phenomenon is refused or flagged. `given_as` says *what* is given; the modes say *how*.

```
Point at it outside the graph? (file, container, config)   → ding 物
A before/after snapshot? ("VM ready", "Risk happened")      → sachverhalt 勢
A named meaning? ("Relay", "Tension")                       → sinn 名
A pattern taking shape? (draft, glimpse, seed, goal)        → bildung 理
A way to do it? (procedure, mode, tool)                     → vollzug 行
How it must be? (rule, norm, invariant)                     → grundsatz 法
```

Confused pairs: **ding / sachverhalt** — can you `ls` it, or does it exist because something happened? **sinn / grundsatz** — what IS vs what MUST BE. **vollzug / grundsatz** — "a way" vs "a must". **bildung / grundsatz** — a pattern, once set and followed, becomes a rule. A `sachverhalt` incident: `pratyakshita`/`atita`/`virodha`, 🔥.

## The nests

| Value | Governing sense · limit | Expected arrows |
|---|---|---|
| `ding` 物 | *res*, *vastu*: has existence outside the graph — `status.json`, an endpoint, a document | `ahara`/`utpatti`, `context` |
| `sachverhalt` 勢 | Ibn Sina's *ḥāl*, "between" substance and absence; found and left by an action (not Husserl's ideal correlate of a judgement) | `ahara` (input condition), `utpatti` (result) |
| `sinn` 名 | *māhiyya*, *artha*: whatness with identity, no outside existence — "Relay", the node types | `vimarsha_of`, `context` |
| `bildung` 理 | *bīja*, *Sinnbildung*: taking shape, not yet form — seeds, assembly patterns, a goal; the early sense of 理 (veins in jade), not the Neo-Confucian set order | `arose_from`, `vimarsha_of`; ontic `anagata` |
| `vollzug` 行 | *upāya*: a path, not a constraint — working modes, tools | `upadhi`, `context` |
| `grundsatz` 法 | *niyama*, *wājib*: what the system can't stand without | `upadhi` (constraint), `vimarsha_of` (challenge) |

The same thing changes `given_as` as it moves along lines of work: a thing understood becomes a name, a name embodied a thing. The test of a value is which arrows the phenomenon accepts.

## The given_as × arrow matrix

✓ expected · ○ allowed · ? suspicious · ✗ not allowed

| Arrow | ding | sachverhalt | sinn | bildung | vollzug | grundsatz |
|---|---|---|---|---|---|---|
| context → holon | ✓ | ✓ | ✓ | ✓ | ✓ | ✓ |
| derived_from → phen. | ○ | ○ | ✓ | ✓ | ○ | ✓ |
| arose_from → any | ? | ○ | ○ | ✓ | ○ | ✓ |
| specifies ↔ phen. | ○ | ? | ✓ | ○ | ✓ | ✓ |
| ahara ← kriya | ✓ | ✓ | ? | ? | ✗ | ✗ |
| utpatti ← kriya | ✓ | ✓ | ○ | ○ | ✗ | ✗ |
| upadhi ← kriya | ○ | ○ | ✓ | ? | ✓ | ✓ |
| vimarsha_of ← vim. | ○ | ○ | ✓ | ✓ | ○ | ✓ |
| addressed_by ← vim. | ○ | ✓ | ✓ | ✗ | ○ | ✓ |
| realized_as ← risk | ✓ | ✓ | ○ | ✓ | ○ | ✗ |
| supersedes | ✗ | ✗ | ✗ | ✗ | ✗ | ✗ |

Between phenomena: `contains`, `derived_from`, `specifies`, `arose_from`.

- **`ahara`/`utpatti` are material.** A method or rule is applied (`upadhi`); the API returns 422 otherwise.
- **`realized_as`:** a risk materialises as a `sachverhalt` — the incident.
- **`addressed_by` by `given_as`:** a distinction or principle answers a doubt, counter-thesis or risk; a state answers an empirical doubt; a method, "how"; a thing, "where/what"; a seed nothing. Distinct from `arose_from`; ends nothing. Accepted ends: `verstak_arrow(action="?")`.
- **No `supersedes` on phenomena:** succession is the consumers moving over.

## Diagnostics by given_as

- `ding` or `sachverhalt` with neither `ahara` nor `utpatti` — orphan thing, dangling state.
- `sinn` with no `vimarsha_of`, `upadhi` or `context` — a dead concept.
- `bildung` with neither `arose_from` nor `vimarsha_of` — a lost pattern. While `kalpita`/`anumita`/`pratyakshita` it is emerging; `pramanita` is a signal to crystallize (`given_as` → `sinn` or `grundsatz`). Ends by crystallization, `badhita`, `virodha` or `visarjana`.
- `vollzug` without `upadhi` — a dead recipe.
- `grundsatz` without `upadhi` — declarative: proposed → work to do; given without a vimarsha → acknowledged, neither applied nor considered.
- `grundsatz` with neither `derived_from` nor `arose_from` — ungrounded, a tension; grounds are an arrow.
- `sinn`/`grundsatz` in `atita` — historical, needn't be applied.
