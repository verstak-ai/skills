# Migrations: the moves an older contract or legacy content calls for

Read whole before the first mutation of a repository whose files show one of the signs **align**, `Contract`, names: a cover `contract` below `9`, a `searcher` role file, a `Cross-project memory` slot, an `Agreement` or hole naming a node, a section the template no longer has. Each move is called by what is found in the files, never by the counter alone: a repository can carry contract 11 and an old section both. The live rules these moves land on — Step 4's transition, Step 5's hygiene, Step 6's roles, Step 7's cover — are the method's; this file carries only what the old form was and where its content goes. Content transfers before anything is deleted.

## From contract 8
The delegation roles are eight (Step 6). Project `weaver`, `recaller` and `ingester` in both harnesses and add them to `.gitignore` by name; delete both of your own `searcher` files and drop them from `.gitignore` (graph search is now `recaller`, for the recall ladder); re-project `designer`'s body, which no longer writes the graph — the volume edit of touched nodes is `weaver`'s, a story's intake `ingester`'s. Each file's tail in `Role file tails` carries over; a `searcher` tail goes to `recaller` where it still applies, else is named in the report.

## From contract 7
Your six role files leave the index and go into `.gitignore` by name — the files stay on disk, others' agents untouched (Step 5); every other clone loses them on its next pull, so say it in the alignment case and the PR body: a receiving copy saves its role files before pulling and puts them back (they are ignored then), else re-projects them by Step 6; each file's repository tail moves into `AGENTS.md`, section `Role file tails`, and its model comes from the person's preferences (Step 6). Branch worktrees live inside the repository, in `.worktrees/` (ignored); abandoned trees and your trees' development caches are cleaned up (**code-work**, `Branch and worktree`, `Cleanup`). Re-project `Git workflow` and `Persistence` from the template, and the tracked-secrets line of `Code conventions` (untrack and rotate; `skip-worktree` hides nothing).

## From contract 6
The git and test rituals changed — one branch and PR per batch, review by the batch's tier, CI on the batch's PR and trunk, tests by the affected. Re-project `Git workflow` and `Test discipline` from the template; a line promising CI on every push, a light review on every finished branch, or a branch per item goes. Keeping a full gate instead of selection needs an explicit, applicable exception from the rule's principal in `Local overrides`; a cost measurement alone grants none. Re-project the push hook's text (Step 4) and the `reviewer` role body (`align-delegation`) above `## This repo`.

## From contract 5
Drop the cover's `Cross-project memory` slot and its source line — personal memory has no place in `AGENTS.md` (Step 1, `No personal memory in AGENTS.md`); an older cover's personal-memory slot and its source line go on the run that finds them.

## From contract 4
Re-project memory routing and guard messages through minding, with no constructed or stored personal address; refresh the ritual and delegation projections against their current references too.

## Old questionnaire
An older cover's `Agreement` or hole names a node (`#N`), at any contract → `verstak_look`: answers → `Project` values; open ones → `open`, the question a message in the case. Release the node (`visarjana`, reasoning "moved to case #N") once the answers stand in the file or the case, not before; not yours → message its author.

## Legacy sections
Sections the template no longer has (`Session lifecycle`, reviews, branches, principles, integration scope, external surfaces, the feedback-reflection region, the `Cross-project memory` slot and its source) → delete, **code-work** and `verstak` own them; a repo fact inside (hook paths, forge) → its slot; a deliberate deviation → `Local overrides` with its reason. Other content with no slot → "Code conventions" or `Local overrides`; a Reality table in `AGENTS.md` moves to `REALITY.md` row by row, its dated observations to graph nodes; a substantive `CLAUDE.md` merges in and becomes the pointer; `Layout` files keep their content, links checked; `nks_*` names become `verstak_*`.
